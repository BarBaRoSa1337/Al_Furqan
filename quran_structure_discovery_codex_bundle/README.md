# Quran Structure and Discovery Codex Bundle

Copy the files under `docs/` into the repository documentation directory.

Primary instruction:

```text
Read AGENTS.md and all project documentation. Then execute
docs/CODEX_QURAN_STRUCTURE_DISCOVERY_PROMPT.md.

Treat the repository as the source of truth. Begin with inspection and baseline
checks. Do not modify files during the first inspection pass.
```

Terminology:

- Juz: 30 divisions.
- Hizb: 60 divisions.
- Rub el Hizb: 240 quarter-Hizb divisions.
- Thumun al-Hizb: an optional source/riwayah-specific eighth-Hizb scheme. It is
  not part of the current Hafs MVP unless an approved Hafs source explicitly
  provides it.
