# MVP Scope

## Product

Quran Habit App for adults, teens 12+, and families.

## MVP Content

Only Surah Al-Fil.

Surah Al-Fil has:
- intro lesson
- ayah 1 lesson
- ayah 2 lesson
- ayah 3 lesson
- ayah 4 lesson
- ayah 5 lesson
- final review
- completion screen

## MVP Features

### Must Have

- Roadmap screen
- Lesson screen
- Quran ayah block
- Translation block
- Word explorer block
- Tafsir/context card
- Quiz block
- Completion screen
- XP placeholder
- Streak placeholder
- Local progress saving
- RTL Arabic support
- Source metadata in content

### Should Have

- Simple image/SVG support
- Basic onboarding
- Reset progress button for testing
- Package validator
- Missing asset fallback

### Later

- Audio playback
- Word-by-word audio
- Recitation practice
- Voice checking
- Supabase auth
- Parent dashboard
- Family accounts
- More surahs
- Subscription
- Scholar review workflow
- Content studio

## MVP Quiz Types

Start with:
- multiple choice
- fill in the blank
- match Arabic word to meaning

Avoid:
- complex drag-and-drop at first
- speech recognition
- timed challenges
- competitive leaderboard

## MVP Progress

Track:
- current concept
- completed concepts
- XP
- streak
- quiz scores

Use local storage only.

## MVP Definition of Done

MVP is done when:

A user can:
1. Open the app.
2. See Surah Al-Fil roadmap.
3. Start Ayah 1.
4. Read Arabic and translation.
5. Learn word meanings.
6. Read tafsir/context.
7. Complete quiz.
8. Save progress.
9. Continue through all 5 ayat.
10. Complete Surah Al-Fil.
